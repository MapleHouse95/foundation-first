# Contributing

Thanks for your interest in contributing.

This project is early-stage, so contributions should stay focused and practical.

## Good first contributions

- improve documentation
- report unclear flows
- suggest safer checklist wording
- improve validation logic
- add tests for API routes or risk-check workflows
- identify security or privacy issues responsibly

## Pull requests

Before opening a pull request:

1. Keep the change small and focused.
2. Explain what problem it solves.
3. Avoid adding unrelated features.
4. Do not include secrets, credentials, private user data, or real user records.
5. Include screenshots for UI changes when useful.

## Security issues

Please do not report sensitive security issues in public issues. See [SECURITY.md](./SECURITY.md).
