# Security Policy

Foundation First includes trust and safety workflows, user-submitted checklist patterns, listing verification logic, and API-route handling. Security review is important to this project.

## Reporting a vulnerability

Please do not open a public issue for sensitive security reports.

If you believe you found a vulnerability, please include:

- affected route, component, or workflow
- steps to reproduce
- potential impact
- suggested remediation, if any

Please avoid including real user data, production credentials, private tokens, or personal information in any report.

## Areas of interest

Security-sensitive areas include:

- input validation
- authorization boundaries
- API route behavior
- secret handling
- dependency vulnerabilities
- unsafe data exposure
- abuse cases around listing or rental-application workflows

## Current status

This is an early-stage public OSS project. Security practices and documentation will continue to improve as the project grows.
